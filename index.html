Brave Crash Test PoC

Gunakan file ini untuk menguji apakah celah keamanan ini bisa dipicu dari halaman web.

Metode 1: Klik Tautan Manual

Coba klik tombol di bawah ini. Jika browser langsung force close, berarti skema internal bisa dipicu via interaksi klik.

Metode 2: Otomatis via Pengalihan JS (Tanpa Klik)

Tombol di bawah ini akan mencoba mengalihkan halaman secara otomatis menggunakan JavaScript setelah jeda 3 detik.
